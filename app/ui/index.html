Counters

Disconnect finishes sending what is queued and then closes. Abort does not. Probe asks the station in Call whether it hears you, and how well, without a session: one frame, one answer, both directions of the path. Beacon puts this station's callsign on the air once, addressed to nobody, so anyone listening can report hearing you. Test session runs the field test with the station in Call: a probe, a message, a file and a short burst at every mode, all recorded — about five minutes of transmitting, sized to what the path can do, and a sidecar the project can learn from. The same button stops it. The other station only has to be listening; Help says how to contribute the result.

Keying and drive

−12 dB

Key puts the radio into transmit with no audio: watch the rig and the interface's PTT light. Tune keys with a steady tone at the transmit level; the level follows the slider while it plays, so set the rig's ALC by ear and eye, then press the button again to stop. Both are refused during a session, and a tone is refused while the channel is busy. The level is saved when the slider is released.

A recording is what the radio delivered, at 48 kHz, and a file beside it saying what the modem made of it — every frame, its SNR, whether it decoded. It is what a bug report about the air should carry, and what field/ keeps.

Getting on the air

          
    
            
  1. Setup: callsign, the radio interface and its three devices, the receive level, save. A sound card, port or callsign change restarts the modem by itself.
    2. 
            
  2. Session → Keying and drive: Key for 1 s should light the rig's transmit indicator; the Tune tone with the level slider sets the drive so the ALC barely moves.
    3. 
            
  3. Session: type the other station's callsign and Connect. Leave the modem listening and it answers a call to your callsign whenever it comes; with recording on, every session is kept.
    4. 
            
  4. Host programs: turn on Host programs in Setup, then point Winlink Express (a Vara HF session, TNC at 127.0.0.1 and the port, auto-launch off) or Pat (varahf) at it.
    5. 
          

        


        

          
Running a test session

          

            A test session is how a contact becomes a measurement the project can use: a
            probe, a message, a file and a burst at every mode, recorded, in about five
            minutes. The other station only has to be listening — a person at the panel or
            an unattended station set to answer only.
          

          
    
            
  1. Agree the contact: a frequency, a time, and the bandwidth (Setup step 4; both stations must run the same one).
    2. 
            
  2. Setup step 1, once: your grid, rig, power and antenna. They go into every recording, so the report needs no follow-up.
    3. 
            
  3. Session: the other callsign in Call, then Test session. The line under the buttons follows each step; the log shows what each one found. The message and the file are sized to what the path can do, and the whole run stops at ten minutes on its own. Stop test ends it earlier, keeping what was learned.
    4. 
            
  4. Wait for complete. The recording is in the recordings folder (Help menu › Open the configuration folder), two files whose names end in _test: the .json is the report, the .wav the audio.
    5. 
            
  5. Contribute it: the button below copies a link to a pre-filled report. Paste it into your browser (a GitHub account is needed, free), drag the .json into the text box, add the .wav zipped if you are happy to share the audio, and Submit.
    6. 
          

          

            
            open the report
          

          

        


        

          
Reading the panel

          
    
            
  • SNR is what this receiver measured on the last frame it found, referenced to 3 kHz. They hear you at is what the other station measured on your last burst, carried back in its acknowledgement.
    • 
            
  • Tuning is the carrier offset the receiver removed: positive means the other station is above your dial. A few hertz is nothing; a hundred is a dial to check.
    • 
            
  • Throughput counts application bytes both ways over the last thirty seconds. Mode is the rate the sender is using; the Diagnostics tab shows the rate controller's smoothed SNR and the margin it keeps above the mode's threshold.
    • 
            
  • Signal above noise and the level chart are the busy detector's view of the channel; Receive level is the sound card's, which the Setup tab helps you set.
    • 
            
  • Stations lists everyone whose frame carried a callsign; Compact in the header shrinks the panel to the state and four readings for a small window.
