# The link review's research code

Frozen evidence for ADR-0069 (granted slots) and its steps: the adversarial simulator, the
campaigns, the prototype engines, the TLA+ models and their results. It runs at `b0d422c`, the
last tree with protocol 7's engine, which ADR-0069's Step 5 deleted; it is excluded from lint and
from CI. How to run it is in
[`docs/research/link-architecture/README.md`](../../docs/research/link-architecture/README.md),
under "Reproduction".
