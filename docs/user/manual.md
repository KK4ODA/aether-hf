# The operator's manual has moved

[**docs/manual/manual.md**](../manual/manual.md): one illustrated manual, with a table of
contents, schematics and screenshots, and a PDF beside every release. This page stays so that
the links older installations and other documents hold into the old manual still land somewhere.
Each heading below is one of the old manual's, and says where its subject is now.
