# RadioPost

RadioPost, the federated email system for amateur radio first sketched here, has its own
repository: [KK4ODA/RadioPost](https://github.com/KK4ODA/RadioPost). The concept, the detailed
design and the protocol specifications live there. Aether is its first modem; RadioPost reaches it
through the modem interface (RPMI, RadioPost's RP-4), which maps onto Aether's control API.
